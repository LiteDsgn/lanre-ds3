# Assets

No logo, wordmark, illustration or icon files were provided for this system, only reference screenshots of other games (used as mood/structure references only; they are **not** redistributable brand assets and are not included in this repo).

What belongs here when it exists:
- `logo/`: wordmark and app icon (until then, render "Lanre" with `.mp-display` + `.mp-outline`).
- `world/`: painted environment art (cottage, trees, landmarks). Components reserve striped slots for it (see `guidelines/brand-imagery.html`).
- `prizes/`: rendered prize art (gift boxes, chests, coin piles). `GameIcon` glyphs stand in meanwhile.
- `characters/`: mascot / creature sprites.

Icons are not files: Phosphor Icons (FILL + BOLD weights) are linked from CDN in `tokens/icons.css`.

Lanre is for mobile games built around a world map. A winding trail of level pucks, expedition boards, a camp inventory, and the panels every casual game needs.

It's bright, chunky and tactile. Painted meadow greens, sky-blue actions, gold rewards and wood frames. Everything you can press has a solid bottom edge.

It started from nine reference screenshots of casual games. The name, palette, type pairing and components are original.

## Two layers

- **The base kit** is a general casual-game system. Buttons, HUD pills, panels, map pucks, rewards, forms and feedback.
- **The Birthday Adventure layer** adds what Lanre's Birthday Adventure needs. Themed worlds, mystery levels with mixed media, identity reveals, gemstones, discoveries and the contributor flow.

## Where things live

- **These docs** explain the rules and show every component live. Props tables come from each component's `.d.ts`, and usage notes from its `.prompt.md`.
- **Storybook** has every state of every component, live controls and accessibility checks.
- **`showcase.html`** is the original showcase. It still works with no build step.
- **The source** is in `tokens/`, `components/` and `guidelines/` at the root of the repo.

## Run it locally

```bash
npm install
npm run docs
```

The docs open on port 3000. Run `npm run storybook` alongside it so the Storybook links work.

This layer comes from the build brief of 12 September 2026. The base kit stays underneath it, and this adds the components and rules the brief needs.

Every name in these docs and in Storybook is a fictional fixture. There are no real quiz facts, narrator lines or letter text here.

## Two audiences, two surfaces

**The recipient’s experience** is iPad-first. Phones work too, with no hard block on any device.

Opening → map → level → reveal → progress → summit.

**The contributor flow** is phone-first and needs no account.

Onboarding → composer → theme → suitability → preview → submit → optional quiz → gem and leaderboard → private edit link.

## Rules that never bend

- The recipient’s surfaces never show score, rank or tier text. Only the stone.
- Mystery surfaces never carry the sender's name, portrait, gem, filenames or data hidden in the page.
- Media never plays by itself or moves on by itself. Finishing a level is always an explicit Continue.
- "Just tell me" is always offered. Affection is never gated behind a right answer.
- Worlds are applied with `data-world`, never by hand-picking colours.
- Use fixture names only. Never invent quiz facts or letter text.

## Still open

The orientation, final title, narrator copy, quiz questions, letter, private access mechanism and upload limits are all still to be decided.

1Contributor flow on a phone, layout only

Phone frame 390 × 844 (shown at 80%), the same treatment as the iPad canvas: wireframes with numbered callouts, boxes are components from the system (StepBar, TextField, UploadTile, WorldChip, RadioCard, Gemstone, LeaderboardRow). Built from BUILD-BRIEF, CLAUDE-HANDOFF and DATA-CONTRACT v0.1: each frame's notes name the contract fields it writes. Names, titles and clues are fixtures; quiz text is a labelled draft; media limits are proposed defaults. Gold is the contributor CTA (dark text); teal stays Babe's.
